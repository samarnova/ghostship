# Monstahh - Ghostship

just a random fun halloween themed game made using the p5.js library
 (used it for the first time)~

## How to Play
- **Objective:** Use your catching net to hunt and capture the furious ghost
- **Controls:** Click your mouse over the ghost to catch it and score points
- **The Challenge:** You have a **15 second timer** to grab as many ghosts that appear as you can
- **Retry:** If time runs out, slap the **SPACEBAR** to reset/replay n try again

## Visual Features
- **Custom Cursor:** Replaced the boring system arrow with a
- **Arcade Monster Art:** A ghost inspired somewhat by pacman featuring a deep maroon layout, angry eyebrows, and sharp teeth
- **Sinister Atmosphere:** A graveyard backdrop complete with transparency n layered drifting fog clouds rolling over a glowing moon and curved R.I.P. tombstones sitting along the grass line in the back

## Built With
- **p5.js** - Creative JavaScript framework for rendering canvas graphics, mouse interactions, clock management
- **HTML5 & CSS3** - Structural frontend framing n responsive styling sheets
